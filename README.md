# Mais Bichos — proposta demonstrativa

Site original e responsivo para a Mais Bichos Centro de Saúde Animal, no Bom Fim, Porto Alegre. HTML, CSS e JavaScript sem backend ou compilação.

- Site: https://gusdias-coder.github.io/mais-bichos/
- Repositório: https://github.com/gusdias-coder/mais-bichos

## Visualizar e editar

Abra index.html ou execute python -m http.server 8765 na pasta do projeto. Edite conteúdo e contatos em index.html; layout e cores em styles.css; mensagens do WhatsApp e filtros em script.js. Fotos em assets/images/, fontes em assets/fonts/.

## GitHub Pages

Repositório público mais-bichos, branch main, pasta raiz (/), com .nojekyll. Recursos relativos funcionam no subdiretório /mais-bichos/. Após commits, aguarde a publicação do Pages.

## Funcionalidades e acessibilidade

Menu móvel, filtros de serviços, galeria ampliável, perguntas frequentes, WhatsApp, ligação, rotas e Instagram. WhatsApp solicita informações sem confirmar consulta. Sem pagamentos, formulários, cadastro ou armazenamento.

Idioma pt-BR, títulos hierárquicos, foco visível, textos alternativos, atalho de conteúdo, estados acessíveis do menu e filtros, anúncio de resultados, diálogo nativo e movimento reduzido. Consulte VALIDACAO.md.
